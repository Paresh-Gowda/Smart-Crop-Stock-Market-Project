# 🌾 Smart Crop Stock Market

A web-based crop market dashboard that helps users explore agricultural commodity prices, market trends, and price movements.

The **frontend is currently completed**, featuring an interactive dashboard, crop search, market analysis, watchlist UI, market movers, and dynamic price charts. The project is built using **React, JavaScript, React Router, and Recharts**.

Backend development, real-time data integration, and additional functionality will be added in future updates.
